# CARNOT

Flagship product of The Entropy Program;
Carnot, is a markdown editor for Windows \
(This README is written with CARNOT!)

<img width="1600" height="867" alt="image" src="https://github.com/user-attachments/assets/a3c6471e-5bc4-4024-9c2a-b05065684ddf" />


## ✨ Features

- Real-time markdown preview
- Dark theme optimized for writing
- Quick formatting toolbar (bold, italic, headings, lists etc)
- Open and save .md files
- Powerful and fast
- No login, no ads, completely free

## 📥 Download

### 🚀 Installation

1. Download `Zipped folder`
   <img width="1577" height="659" alt="image" src="https://github.com/user-attachments/assets/2aadc462-e805-4c5f-ad52-e9418a35b1c8" />

2. Extract everything.
3. Install the certificate before executing the MSIX.
   1. Run `carnot_cert.cer` file.
      
   2. Install Certificate for `Local Machine`.
      \
      <img width="596" height="756" alt="image" src="https://github.com/user-attachments/assets/7713896f-547a-4607-99a3-432e1b6aee72" />

   3. `Place all certificates in the following store` then `Browse` till you see the `Trusted Root Certification Authorities` option, select it
      \
      <img width="784" height="758" alt="image" src="https://github.com/user-attachments/assets/ed5f3799-a437-4aa9-a752-877f48e4c9a5" />

   4. click `Next`

4. Finally, execute the MSIX file, the installation should complete soon!
